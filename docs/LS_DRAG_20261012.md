# MoonRay LS drag responsiveness investigation

Base: `928f98e`, MoonLightIPR. Scene: the user-supplied `cheetah_moonray.lxo`.
All launches use Modo 16.1v9, private profiles and `TestPreviewAstraLS` preferences; the source scene is never saved.

## Changes under evaluation

- SceneWriter compares RDLA and encodes full/delta payloads on its worker. Dispatch accepts a delta only when its acknowledged base is still the exact same request; otherwise it sends the complete scene without comparing on Modo's thread.
- During an LS drag, host edit notices trigger updates without calculating the complete scene digest. Release performs a normal digest and final update.
- While the writer is busy, drag notices remain queued. Host reads no longer deliberately compete with its Python work.
- Eligible mesh-transform updates refresh owners and descendants rather than every mesh. Instancers, replicators, channel modifiers, unknown owners, and unclassified edits retain conservative refresh behavior.
- Modo scene access and shared-memory publication remain on its main thread. This does not remove the Python GIL or make rendering instantaneous.

## Baseline

Three-second scripted drag phases: camera 14 submissions, 42.6 ms median tick, 21.0% tick share, 38 of 101 scheduled moves; mesh 11 submissions, 67.6 ms median tick, 26.3% tick share, 53 of 101 scheduled moves.

The probe counts render submissions, not completed image updates. Its tick share excludes callbacks outside the tick and other viewport work. cProfile and Python-driven motion add overhead. No claim about the feel of a real mouse drag follows from these measurements.

The baseline wrote its complete report and then exited with 0xC0000409. This is a pre-existing shutdown failure in this isolated preview test, not a passing shutdown check.

## Reproduction

Set `MOONRAY_PROBE_SETTLE=1`, `MOONRAY_MODO_PREFERENCES=TestPreviewAstraLS`, `MOONRAY_PROBE_ENGINE=moonray_ls`, and `MOONRAY_PROBE_SCENE` to a saved scene. If testing MoonLightIPR workflows, point `MOONRAY_MODO_MOONLIGHTIPR` at the matching staged GPU runtime.

Run `tools/run_isolated_preview_probe.py live_cost --runtime <native-runtime> --profile astra-ls-cost --results ls-cost --timeout 120` with the standalone Python environment. Reports stay in this checkout's test-results folder. The wrapper adapts the existing probes' hard-coded paths without changing the primary checkout.

Required functional probes: modes, restarts, draft_events, draft_region, draft_off, playblast, output_stop, compositor, stop_finishes. Inspect their JSON reports as well as process exit status; these probes record behavior rather than enforcing all assertions themselves.

## Validation status

Standalone suite: 339 tests, successful with 17 host/runtime-dependent skips. Prepared-delta tests explicitly reject stale bases without doing a main-thread comparison. The 18 host worker/lifecycle checks passed without skips and with a normal exit. Six targeted transform checks also pass.

## Paired final measurements

The baseline kit was preserved from the first profile, and rerun with the same instrumentation as the candidate. The median below counts only ticks that submitted an update, avoiding a misleading median dominated by skipped ticks.

- Camera, baseline to candidate: 14 to 12 submissions per roughly three seconds; 43.1 to 26.1 ms median submitting tick; 22.9% to 10.5% tick share; 46/102 to 49/100 scripted moves.
- Mesh, baseline to candidate: 11 to 10 submissions; 71.5 to 51.0 ms median submitting tick; 27.1% to 17.1% tick share; 53/100 to 57/100 scripted moves.
- Both completed release settlement with a string digest, no pending digest, and zero mesh-transform mismatches against Modo.

This cheetah scene still uses the conservative full-transform refresh; the selective path is not credited for this scene's measured gain. Capture and Python/GIL contention remain, and real mouse smoothness has not been verified.

All eight requested functional probes completed their scripted reports without Python exceptions. Restart probes submitted once per engine; playblast produced four frames, submitted nothing during playback and once on stopping; output Stop saved beauty and denoised EXRs; compositor edits did not rerender. Every graphical probe still exited abnormally with 0xC0000005. The paired baseline also exits abnormally. This is not a clean regression-suite pass.

The older stop_finishes probe uses stale realtime button assumptions and is not accepted as proof of keep_progress. A new direct probe confirms an unfinished persistent pass can hand over beauty, albedo, and normal buffers; its cleanup retest is recorded separately below.
